# Chess_Ref_with_SFML 重构计划

**当前版本：V0.0.0 开始节点**

这是一份空白节点方便对照。

## 重构目标
- 基于 EasyX 的国际象棋项目编码形式被 Unicode 卡死，现在选择用 SFML 重构。
- 优化输入架构，使其不再依赖黑板。
- 渲染由 SFML 重写（尤其是贴合 SFML 可调整窗口大小），在渲染 UI 方面要完全重写。
- 棋子考虑采用加载图片而不是 Unicode。
- 后续可以考虑逻辑渲染开多线程和窗口可调整。
- 老 `common.h` 太重，考虑设计分离 `common` 和 `config`。
- 逻辑可直接复制粘贴（当然，棋子存储数据结构可以优化重构）。
