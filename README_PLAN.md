# Chess_Ref_with_SFML 重构计划

**当前版本：V0.0.1 完成输入重构**

## 已完成 (V0.0.1)
- **输入架构**：采用 SFML 事件触发替代 EasyX 轮询获取；将 MSG 分离为采集、翻译、写入三部分。
- **移除黑板**：直接输入，`input` 类持有需要输出的数据（在 poll 里完成构造，而不是调用 get 方法临时获取）。
- **框架搭建**：因 SFML 强绑定窗口，顺带搭出 `render` 框架（目前仅负责管理窗口、传递事件和渲染测试用例）。
- **职责分配**：`main` 持有并统一管理 `input` 和 `render`，数据黑板仅作逻辑层内部数据交流
- **配置文件**：完全重构 `common.h`，分离出 `config.h`，后续考虑读取 txt 文本。
